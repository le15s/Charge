Charge is a workout planner and tracker.

### What you can do

* Set up your profile in a few short steps: body, goal, where you train and how often.
* Create several workout routines, or ask the assistant to propose them.
* Swap any exercise you don't like with one tap.
* Run a live workout with a rest timer between sets and checkmarks for completed sets.
* Review your history and personal records.

The exercise library comes from the open-source [free-exercise-db](https://github.com/yuhonas/free-exercise-db) project.
